🎨 主题

点击卡片即可切换主题；主题文件位于 themes/ 目录，修改后刷新即生效。

🎨 主题

主题文件位于 themes/ 目录，到 🎨 主题页 点击卡片即可切换；修改主题文件后刷新即生效。

🧩 自定义注入（js / css / html）

与 alist 一致：向所有页面（前台 / 后台 / 编辑器）全局注入自定义内容，保存后刷新页面生效。

自定义头部 HTML / JS（注入 <head> 尾部）
自定义尾部 HTML / JS（注入 </body> 前）
全局 CSS（注入 <head> 的 <style>）
🧸 扩展（小控件 / 看板娘等）

扩展位于 extensions/<名称>/ 目录（index.js / index.css），自动注入所有页面，修改后刷新即生效。

🧩 分组管理（主题脚本 / 小控件 / 看板娘）

每个分组 = extensions/<名称>/ 目录，组内可含多个文件（js / css / html / 资源），index.js 与 index.css 自动注入所有页面；可克隆分组。

选择左侧分组进行编辑，或新建分组
