# 扩展目录（运行时热加载，无需重新编译）

将任意扩展放入本目录下的独立子文件夹，例如：

```
extensions/
  live2d/          # 看板娘扩展
    index.js       # 入口脚本（会被注入到所有页面）
    model/         # live2d 模型资源
  analytics/       # 访问统计
    index.js
```

服务端会扫描本目录，将每个子文件夹下的 `index.js` / `index.css` 注入到**所有页面**（前台 + 后台），
修改后刷新页面即可生效。此为 alist 风格的扩展机制，兼容看板娘等原生扩展。
